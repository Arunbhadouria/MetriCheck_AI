# Rule Set Changelog

## Version 2026.01 (Active)
- **Effective Date**: 2026-01-01
- **Description**: Initial baseline compliance rule set implementing Legal Metrology (Packaged Commodities) Rules, 2011 with 2026 amendments.
- **Implemented Rules**:
  - `RULE-6-1-A`: Manufacturer & Complete Address verification.
  - `RULE-6-1-B`: Generic Product Name verification.
  - `RULE-6-1-C`: Net Quantity Standard Metric Units check.
  - `RULE-6-1-D`: Month and Year of Manufacture/Packing check.
  - `RULE-6-1-E`: Retail Sale Price / MRP declaration format check.
  - `RULE-6-1-F`: Consumer Care Contact Details presence check.
